<h1 id="dataset"><span class="num">1</span>Dataset</h1>
<p class="desc">Each pair is built from one real clip: the named object is segmented with a text-prompted video segmenter and inpainted out, and its sound is separated out of the soundtrack. A pair is used in both directions — original → edited for removal, edited → original for addition. 24,444 training / 1,389 validation / 1,425 test pairs; the test set covers 374 object descriptions.</p>
